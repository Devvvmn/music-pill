# Music Pill - Cosmic DE Applet

Ты создаёшь новый аплет для Cosmic DE в стиле macOS Music Pill (маленькая пилюля в доке с управлением музыкой).

## Требования

### Внешний вид (macOS Music Pill стиль)
- Округлённая пилюля (border-radius: очень большой)
- Компактный размер (примерно 180x60px в спокойном состоянии)
- Фон: полупрозрачный blur-glass (glassmorphism)
- Анимация при наведении: небольшое расширение
- Отображение: обложка трека + название + прогресс-бар

### Функционал
- Показывает текущий трек (название, исполнитель)
- Кнопки: Play/Pause, Previous, Next
- Прогресс-бар с временем воспроизведения
- Volume slider
- Иконки с SVG
- Интеграция с MPRIS (D-Bus)

### Фреймворк
- **Язык**: Rust
- **Фреймворк**: libcosmic (iced-based)
- **Структура**: типичный Cosmic applet структур

## Файлы для подтягивания

Подтяни в эту папку:
1. Шаблон апплета (Cargo.toml, src/main.rs структура)
2. Примеры управления D-Bus / MPRIS
3. Примеры компонентов libcosmic с стилизацией
4. Гайд по созданию апплетов для панели

Используй libcosmic документацию и cosmic-applet-template как основу.
